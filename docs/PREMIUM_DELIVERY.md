# مدونة معتز العلقمي — تقرير الإصدار 2.0.0

برمجة وتطوير: معتز العلقمي — تعز — اليمن — 2026م.

## المقارنة الهندسية

| الجانب | الإصدار السابق | الإصدار الجديد |
|---|---|---|
| الواجهات | Java Activities وتخطيطات يدوية | Kotlin وJetpack Compose وMaterial 3 وNavigation |
| البنية | مخزن JSON واحد | MVVM وRepository وHilt وRoom وFlow |
| القراءة | تنسيق نص بسيط وحجم خط مؤقت | CommonMark وعناوين واقتباسات وجداول وتحديد النص وإعدادات خطوط وسطور ووضع ليلي |
| المحفوظات | SharedPreferences | Room مع ترحيل معرفات المحفوظات السابقة |

| الإصدار | Debug، توقيع الإنتاج متخطى | مسار توقيع إنتاجي واستعادة مشفرة وفحوص شهادة وSHA-256 |

## بنية المشروع

- `src/`: موقع React/Vite ولوحة الكاتب القائمة.
- `api/`, `server/`: واجهات الخادم والمصادقة والاستعلامات المعلّمة.
- `db/`: المخطط وترحيل البيانات التحريرية دون استبدال المقالات.
- `android/.../data/`: عقد API وRoom والمستودع وتفضيلات DataStore.
- `android/.../domain/`: تطبيع البحث العربي.
- `android/.../ui/`: الشاشات والقارئ ونظام التصميم ومحرك Markdown.
- `android/release/`: خطوات الإصدار وشهادة استعادة عامة فقط.
- `.github/workflows/`: فحص الويب وبناء Android واختبارات الأجهزة ومسار النشر.

## الاتصال والقراءة دون إنترنت

التطبيق يتصل بـ`https://motazalqmi.vercel.app/api/v1/sync` عبر Retrofit/OkHttp. الخادم وحده يستخدم DATABASE_URL للوصول إلى Neon. لا تصل أسرار Neon أو كلمات مرور الإدارة إلى APK.

تُحفظ المقالات والأقسام والاقتباسات محليًا. توجد نسخة تأسيسية من المحتوى المنشور فعلًا لتشغيل التطبيق أول مرة دون شبكة. تُطبّق لقطة المزامنة الكاملة داخل معاملة واحدة؛ الاستجابة الناقصة أو المكررة أو التي تتضمن مسودة تُرفض قبل تغيير المكتبة. تُعلّم المقالات المسحوبة بأنها غير متاحة، وتبقى المحفوظات وسجلات القراءة مستقلة. تنظيف التخزين يحافظ على المحفوظات وسجل القراءة.

المزامنة الخلفية كل ست ساعات طلب جدولة، وقد يؤخرها Android. لا توجد وعود بتحديث فوري أو Push. الصور اختيارية وفق إعداد الشبكة؛ النصوص والخطوط مرفقة أو مخزنة محليًا.

## واجهات API

`health`, `bootstrap`, `articles`, `article?slug=`, `articles/{slug}`, `categories`, `quotes`, `about`, `android`, `search?q=`, `featured`, `sync?since=`, `config`, `versions`.

العقد والأمثلة في API.md. الاستجابات العامة تستبعد المسودات، وتستخدم JSON وETag والتخزين المؤقت المناسب. المزامنة كاملة وليست فروقًا جزئية؛ غياب معرف من اللقطة الكاملة يكشف السحب أو الحذف. حدود الحجم الموثقة: 2000 مقالة و3 MiB للقطة؛ تجاوزها يفشل بأمان بدل حذف المحتوى المحلي خطأً. Rate limiting داخل كل نسخة خادم مع حدود ذاكرة؛ ليس حدًا موزعًا عالميًا عبر كل مناطق الاستضافة.

## التحقق

النتائج النهائية وروابط CI والشهادة وملف APK تُضاف بعد انتهاء تشغيل الإصدار. لا يُعد نجاح الترجمة دليلًا على اختبار جهاز فعلي أو قياس FPS أو البطارية.

## التوقيع والتوافق

معرف الحزمة ثابت: `com.moataz.motazalqmi`. الإصدار `2.0.0`، الكود `20000`، الحد الأدنى API 26. عند غياب مفتاح إنتاج سابق يُنشأ مفتاح جديد؛ لا يمكنه تحديث نسخة Debug السابقة مباشرة. ترحيل المحفوظات يعمل عند الاحتفاظ ببيانات الحزمة وتوافق شهادة التوقيع. لا تزل النسخة القديمة قبل تأمين بياناتها.

شهادة الاستعادة العامة في GitHub؛ مفتاح الاستعادة الخاص محفوظ لصاحب المشروع خارج المستودع. لا تنشر المفتاح الخاص أو أرشيف التوقيع بعد فك تشفيره. يجب استخدام مفتاح الإنتاج نفسه لكل تحديث لاحق.

## الحدود

- لا توجد لوحة كاتب داخل Android؛ الإدارة الآمنة القائمة على الموقع هي المرجع.
- لا يوجد اختبار مادي على هاتف ARM64 في هذه البيئة، ولا أرقام أداء ميدانية مفترضة.
- عرض Markdown أصلي عبر TextView؛ لا تنفيذ HTML أو JavaScript، ولا WebView. الصور الداخلية في Markdown لا تُحمّل؛ صور الغلاف مدعومة.
- المزامنة الحالية لقطة كاملة محدودة الحجم، وليست نظام تغييرات تاريخي غير محدود.
