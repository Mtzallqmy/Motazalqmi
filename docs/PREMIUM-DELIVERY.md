## التصميم والوظائف

خلفيات ورقية دافئة، حبر بني، تمييز ذهبي وتفاعل بترولي، ووضع ليلي مستقل. تنقل أصلي باتجاه RTL، بطاقات مقالات وأقسام، واجهة اقتباسات، بحث عربي عبر العنوان والمحتوى والمؤلف والكلمات المفتاحية واسم القسم، ومكتبة للمحفوظات وسجل القراءة والمقالات غير المكتملة.

القارئ يدعم Markdown والجداول والقوائم والاقتباسات، ويحافظ على فواصل الأسطر الشعرية، مع تحديد النص ونسخه ومشاركة الرابط الرسمي وتغيير الخط والحجم والتباعد واسترجاع موضع القراءة. عرض النص من دون WebView أو تنفيذ HTML. الروابط الخارجية مقيدة بمخطط HTTPS.

## البنية

`android/app/src/main/java/com/moataz/motazalqmi/`: data، domain، ui، مع BlogApplication وMainActivity. يربط Hilt بين Room وRetrofit والإعدادات. يتلقى ViewModel تدفق Room فتظهر البيانات المحلية قبل الشبكة. شروح البناء والتوقيع في android/README.md.

## Neon وواجهات الخادم

اتصال التطبيق: Android → HTTPS API على Vercel → Neon PostgreSQL. لا توجد بيانات اتصال PostgreSQL أو كلمة مرور مدير داخل التطبيق. لم يتغير نظام إدارة المقالات أو معرّفاتها. أضيف جدول بيانات تحريرية بترحيل غير هدّام اختُبر أولًا على فرع Neon منفصل ثم طُبّق على القاعدة الحالية.

التحقق الحي موثق في docs/API-VERIFICATION.json: health، bootstrap، articles، categories، quotes، android، sync، search، featured، config، versions، ورابط مقال بصيغته الجديدة. عادت جميعها بحالة HTTP 200، وعادت إعادة طلب sync باستخدام ETag بحالة 304. الصفحة الرئيسية بقيت متاحة بحالة 200.

اختبارات Node: 15 حالة ناجحة، تشمل نشر المحتوى وحدود البحث والتطبيع العربي والمزامنة الفارغة وفشل الخادم ورفض التعديل وETag والمصادقة وتقييد الاندفاع. حدود الاندفاع محلية لكل مثيل خادم، وليست حصة موزعة عبر كل مثيلات Vercel.

## العمل دون إنترنت وحماية البيانات

تُضمَّن لقطة من المحتوى المنشور الفعلي: 7 مقالات و8 أقسام و4 اقتباسات مع سجل مصدر وبصمة SHA-256. لا تُستخدم أمثلة غير منشورة لملء الأقسام. يستورد التطبيق ملف التخزين القديم ومعرّفات المحفوظات دون حذف الأصل.

تُفحص الاستجابة كاملة قبل تطبيقها. يستبدل Room مجموعة المنشور داخل معاملة واحدة، ويحافظ على حالات القارئ. تبقى المقالات المسحوبة التي حفظها المستخدم مع تنبيه بأنها نسخة محلية؛ تُزال النسخ غير المحفوظة من العرض العام. فشل الشبكة أو نقص الاستجابة لا يؤدي إلى مسح المكتبة. صور الأغلفة اختيارية عبر Wi-Fi مع الاستفادة من المخزن المؤقت.
