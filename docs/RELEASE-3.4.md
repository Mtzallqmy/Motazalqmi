# مدونة معتز العلقمي 3.4 · أبواب المجلة

يتبع التطبيق بنية الموقع الحالية: هيدر يحمل الاختصارات نفسها، قائمة بالأبواب، تصنيف بأيقونته ووصفه، مقالة مميّزة، أحدث الكتابات مع التصفية والفرز، ورفوف للكتب والأدب العربي. الرسومات مستخرجة من مجموعة Lucide التي يستخدمها الموقع، وترخيصها مضمّن في التطبيق.

تفتح هوية الكاتب صفحة تعرض نبذته ورابطه وكتاباته. تحمل استجابة المزامنة ملفات الكتّاب العامة مع المقالات في استعلام Neon واحد، وتلتقط بصمة المزامنة أي تعديل لهذه الملفات. يحتفظ التطبيق بها في قاعدة Room القائمة عند العمل دون اتصال. المقالات القديمة التي تستخدم اسم الكاتب فقط تظل قابلة للتصفح بالاسم. لم يحتج التغيير إلى ترحيل لقاعدة البيانات.

تدعم بطاقات المقالات المشاركة والحفظ والإعجاب المحلي. تعرض المقالة الوسوم القابلة للبحث والمقالات المرتبطة. تشمل إعدادات القراءة عرض النص والمحاذاة وتباعد الفقرات وخط الكاتب وحجمه، إلى جانب فهرس المقال والمظهر الليلي. تبقى محفوظات الموقع ومحفوظات التطبيق محلية لكل جهاز أو تثبيت.

تضم لوحة الكاتب البحث وتصنيف المقالات بحسب حالة النشر، وإدارة الكتّاب والوسائط، وهوية المدونة والاقتباسات، وفحص اتصال Telegram. إنشاء رمز ربط حساب Telegram يتم من لوحة الموقع. يمكن استعادة مراجعات المقالة من سجل الخادم إلى المحرر، ثم مراجعتها وحفظها.

يتحقق سير العمل من بناء الموقع واختبارات Chromium وAndroid، ومن التوقيع والمحاذاة وبصمة SHA256 وملف ARM64 الموقّع. يختبر واجهات Compose على API 26 و28 و29، وتثبيت APK النهائي وتشغيله دون اتصال على محاكي API 35 بترجمة ARM. سجل GitHub Actions يبين نتيجة كل اختبار. النسخة المستقلة تستخدم `com.moataz.motazalqmi.edition341` وتظهر باسم «مدونة معتز العلقمي ٣.٤.١». تحتفظ التثبيتات الأقدم بالمحفوظات الموجودة داخلها.

تستخدم 3.4.1 أنواع Gson الصريحة عند قراءة قوائم الأقسام والاقتباسات والكتّاب من Room. أضيف فحص ظهور أول باب في الشاشة الرئيسية عند تشغيل APK المصغّر دون اتصال، بعد أن أظهرت لقطة 3.4.0 غياب الشريط.
