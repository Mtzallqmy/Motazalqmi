# مدونة معتز العلقمي — 2.0.0

إعادة بناء أصلية بـ Kotlin وJetpack Compose؛ واجهة عربية باتجاه RTL وألوان ورقية وبترولية، وخطوط Amiri وNoto Naskh Arabic وIBM Plex Sans Arabic المضمّنة.

- أقسام المدونة الثمانية، والمقالات والاقتباسات من المصدر المشترك.
- قارئ Markdown أصلي، تحديد ونسخ النص، مشاركة الروابط الرسمية، حجم وخط وتباعد قابل للتعديل، قراءة مركزة ووضع ليلي.
- محفوظات وسجل قراءة ومواضع محفوظة في Room، وإعدادات دائمة في DataStore.
- محتوى منشور حقيقي لأول تشغيل دون شبكة، ومزامنة دورية ومدفوعة يدويًا مع Neon عبر API الخادم.
- تطبيق كامل للتحديثات والحذف داخل معاملة واحدة؛ تبقى النسخ المحفوظة مع إشارة إلى توقف نشرها.
- ترحيل محفوظات الإصدار القديم دون حذف ملفاتها.

الحزمة: com.moataz.motazalqmi. الإصدار: 2.0.0، الرمز: 20000. الحد الأدنى Android 8.0/API26. حزمة الإنتاج ARM64.

التوقيع: شهادة Release جديدة، وليست شهادة Debug. لا يمكن التحديث المباشر فوق تثبيت ذي توقيع مختلف. الاحتفاظ بمفتاح التوقيع الجديد ضروري لاستمرارية تحديثات هذه السلسلة.

لا يتضمن التطبيق وضع إدارة للكاتب؛ لوحة الموقع الحالية هي مصدر إدارة المحتوى. لا يُضمَّن DATABASE_URL أو كلمات مرور الإدارة في التطبيق.

حدود التحقق: اختبارات المحاكي لا تثبت الأداء على هاتف ARM64 فعلي؛ لم تُقَس البطارية أو زمن الإقلاع على أجهزة المستخدم. حد المزامنة الحالية 2000 مقال/3 MiB للاستجابة؛ يتطلب التوسع الأكبر ترقيم لقطات ثابتة.

برمجة وتطوير: معتز العلقمي — تعز — اليمن — 2026م.
