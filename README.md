# مدونة معتز العلقمي — Neon + Vercel
مدونة ثقافية عربية بتصميم RTL، React 19 وVite 6، وخادم API على Vercel Functions وقاعدة Neon PostgreSQL.

## التهيئة
1. اربط مستودع GitHub بمشروع Vercel: إطار Vite، الإصدار Node 22، الأمر npm run build، المخرج dist.
2. قاعدة Neon خاصة مستقلة: motazalqmi-blog. مخطط البيانات في db/schema.sql. لا ترفع بيانات الاعتماد إلى GitHub.
3. أضف في Vercel > Environment Variables (خادمية فقط، بلا VITE_): DATABASE_URL (اتصال Neon pooled)، ADMIN_EMAIL، ADMIN_PASSWORD_HASH، SESSION_SECRET.
4. لإنشاء كلمة مرور قوية وتوقيع جلسات، شغّل محليًا npm run admin:generate، واحتفظ بكلمة المرور سرًا، ثم أضف فقط المشتق والمفتاح إلى Vercel.
5. أعد النشر، ثم افتح /admin/login، وانشر المقالات أو استورد المقالات السبعة من لوحة الكاتب عندما تكون القاعدة فارغة.

الواجهة العامة تستخدم GET /api/articles وتعرض المنشورات فقط. طلبات الكاتب تمر عبر جلسة HttpOnly محمية بالتوقيع، وفحص Origin، وحماية من محاولات الدخول المتكررة. لا يحتوي المتصفح على DATABASE_URL.

## التشغيل والفحص
```bash
npm install
npm run check
npm test
npm run build
```
للتشغيل المحلي مع واجهات API استخدم vercel dev بعد إعداد .env.local؛ vite وحده يعرض الواجهة فقط.

الأقسام: كتابات عامة، اقتباسات، من بطون الكتب، من وحي الأقلام، أحاديث وأخبار، حكم ومواعظ، أدبنا العربي، حول المدونة.
الإعجابات والمحفوظات محلية على جهاز القارئ وليست عدادات مشتركة. مراجعة حقوق صور المقالات ونسبة النصوص الأدبية لازمة قبل النشر الواسع.
