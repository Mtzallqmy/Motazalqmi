# مدونة معتز العلقمي | Motazalqmi Blog

مدونة ثقافية وأدبية بالعربية (RTL)، React 19 + Vite 6 مع Neon PostgreSQL وقسم إدارة محتوى آمن في Vercel Functions.

## النشر على Vercel

1. اربط مستودع `Mtzallqmy/Motazalqmi` بمشروع Vercel بإطار `Vite`، وNode 22، وأمر `npm run build`، ودليل `dist`.
2. في Neon أنشئ مشروع PostgreSQL مستقلًا، وشغّل `db/schema.sql` مرة واحدة (ثم لاحقًا استخدم migrations للحفاظ على التاريخ).
3. أضف هذه المتغيرات في Vercel Project Settings > Environment Variables (Production / Preview حسب الحاجة):
   - `DATABASE_URL`: سلسلة اتصال Neon (يفضل pooled)؛ **خادم فقط**، لا تضعها تحت `VITE_`.
   - `ADMIN_EMAIL`: بريد الكاتب المخوّل.
   - `ADMIN_PASSWORD_HASH`: مشتق scrypt للرمز؛ شغّل محليًا `npm run admin:generate` لإنشاء كلمة مرور قوية ومشتقها.
   - `SESSION_SECRET`: مفتاح عشوائي لا يقل عن 32 حرفًا، يولّده السكربت نفسه.
4. بعد إضافة المتغيرات، أعد نشر الموقع. لوحة الكاتب على `/admin/login`.
5. أول مرة يمكن استيراد المقالات التجريبية السبعة إلى Neon من لوحة الكاتب (إن كانت قاعدة البيانات خالية).

**تحذير أمني:** لا تضف `DATABASE_URL` أو كلمة المرور أو `SESSION_SECRET` إلى GitHub أو `VITE_*`. لا تعرض اتصال PostgreSQL مباشرة للمتصفح. تُستخدم جلسة `HttpOnly` بتوقيع HMAC وتتحقق واجهات الكتابة من تسجيل دخول المدير والمصدر (Origin) وتتبع المحاولات الفاشلة في Neon.

## تشغيل وفحص

```bash
npm install
npm run check
npm test
npm run dev
```

أثناء التشغيل المحلي تحتاج المتغيرات في `.env.local` وخدمة `/api/*` على Vercel Dev (`vercel dev`)، وليس Vite فقط إذا أردت تسجيل الدخول وحفظ المقالات. Vite وحده يعرض الواجهة التجريبية.

## المحتوى والوظائف

- الأقسام: كتابات عامة، اقتباسات، من بطون الكتب، من وحي الأقلام، أحاديث وأخبار، حكم ومواعظ، أدبنا العربي، حول المدونة.
- البحث والتصفح والوسوم والمقالات المميزة وMarkdown والصور والمحفوظات المحلية.
- لوحة الكاتب: نشر، تعديل، مسودات، حذف، واستيراد الأمثلة السبعة؛ التخزين الدائم داخل `blog_articles` في Neon.
- `api/session.js`: تسجيل دخول وخروج الكاتب واستعادة الجلسة.
- `api/articles.js`: استعراض المنشور للعامة وحماية إدارة المحتوى بالجلسات، ويفرض قواعد صحة البيانات على الخادم.
- `db/schema.sql`: مخطط PostgreSQL والقيود والفهارس ومحدد محاولات الدخول.
- GitHub Actions: فحص الملفات، اختبارات، وبناء Vite.

**ملاحظات:** صور Unsplash والمحتوى التراثي التجريبي يجب مراجعة نسبته قبل النشر النهائي. الإعجابات والمحفوظات تُخزّن محليًا في المتصفح وليست عدادات عامة موثوقة.
