Media: Vercel Blob public store motazalqmi-media is connected to the Vercel blog project. Never expose BLOB_READ_WRITE_TOKEN in the source or Android APK. The authenticated dashboard uploads media directly to Blob, max 100 MiB per file subject to hosting quota. These are public assets, even before a draft is published. Uploads can be referenced by Markdown ![caption](URL) for image/video/audio; PDFs use [caption](URL). Removing articles does not automatically delete media shared elsewhere. Android supports viewing linked media. Embedded native binary uploads are a separate capability.
