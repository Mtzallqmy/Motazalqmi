# توثيق واجهات برمجة التطبيقات — مدونة معتز العلقمي (`API v1`)

- **الرابط الأساسي:** `https://motazalqmi.vercel.app/api/v1`
- **قاعدة البيانات:** Neon PostgreSQL (`motazalqmi-blog`) — الاتصال يتم حصريًا من بيئة خادم Vercel عبر `DATABASE_URL` ولا تُضمّن أي أسرار في تطبيق Android.
- **التنسيق القياسي للاستجابة:**
```json
{
  "ok": true,
  "version": "1.0.0",
  "data": {},
  "meta": { "serverTime": "2026-11-14T16:00:00.000Z" },
  "error": null
}
```

## المسارات المتاحة

| المسار | الوصف | التخزين المؤقت |
| --- | --- | --- |
| `GET /api/v1/health` | فحص جاهزية الخادم واتصال قاعدة Neon | 15 ثانية |
| `GET /api/v1/bootstrap` | التهيئة الأولية (الأقسام + المقالة المميزة + أحدث المقالات + الاقتباسات) | 60 ثانية |
| `GET /api/v1/articles?category=&page=1&limit=20` | قائمة المقالات المنشورة مع ترقيم الصفحات والترشيح بالقسم | 60 ثانية |
| `GET /api/v1/articles/{slug}` | تفاصيل مقال واحد بالمعرّف النصي | 120 ثانية |
| `GET /api/v1/categories` | جميع الأقسام الثمانية مع عدد المقالات المنشورة | 300 ثانية |
| `GET /api/v1/quotes?page=1&limit=50` | قائمة الاقتباسات المنشورة | 120 ثانية |
| `GET /api/v1/search?q=` | بحث في العناوين والنصوص والكتّاب | 30 ثانية |
| `GET /api/v1/featured` | المقالة المميزة الحالية | 120 ثانية |
| `GET /api/v1/sync?since=ISO8601` | مزامنة تفاضلية تُرجع المقالات والاقتباسات المحدّثة وقوائم المحذوف/المسحوب من النشر | `no-store` |
| `GET /api/v1/android` | بيانات إصدار تطبيق أندرويد (`com.moataz.motazalqmi` v2.0.0) | 300 ثانية |
| `GET /api/v1/config` | إعدادات وهوية المدونة | 600 ثانية |
| `GET /api/v1/versions` | إصدارات الـAPI والتطبيق | 300 ثانية |

## الأمان والخصوصية
- جميع الاستعلامات تستخدم Parameterized Queries لمنع SQL Injection.
- المسودات (`status <> 'published'`) والمقالات المحذوفة (`deleted_at IS NOT NULL`) لا تُعرض أبدًا في المسارات العامة، ويُبلّغ عن معرفاتها في `deletedArticleIds` أثناء `/sync` لإزالتها من التخزين المحلي.
- دعم `ETag` و`If-None-Match` (304 Not Modified) لتقليل استهلاك البيانات.
