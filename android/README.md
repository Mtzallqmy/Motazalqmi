# مدونة معتز العلقمي — Android Native v2.0.0

تطبيق أندرويد أصلي مبني باستخدام **Kotlin + Jetpack Compose + Material 3**، ولا يحتوي أي WebView. يقرأ بيانات المدونة المنشورة من واجهات Neon الآمنة المستضافة على Vercel.

- Package: `com.moataz.motazalqmi` (لا يتغير بين الإصدارات).
- `minSdk 26`، و`targetSdk 35`، وإصدار `2.0.0` (`versionCode 2`).
- يدعم **Android 8.0+** وأجهزة **ARM64**. توجد مكتبة أصلية JNI ضمن ABI `arm64-v8a`، وقد تتعذر التثبيت على أجهزة 32-bit.
- Kotlin Compose: الرئيسية، التصنيفات، الاقتباسات، المقالات، البحث، المحفوظات، الإعدادات، والوضع الليلي.
- رابط عميق: `https://motazalqmi.vercel.app/articles/{slug}`.
- مزامنة حقيقية عبر `/api/v1/bootstrap` وصفحات `/api/v1/articles?full=1`; القراءة من النسخة المحلية عند غياب الشبكة؛ تشمل حزمة التطبيق نسخة ابتدائية من المقالات الموجودة وقت بناء الإصدار.
- حفظ المفضلة وحجم الخط والوضع الليلي وموضع آخر قراءة محليًا.
- صور عبر Coil مع التخزين المؤقت الافتراضي. المحتوى الإداري، مفاتيح Neon، وكلمات مرور الكاتب ليست ضمن APK.

## البناء محليًا

يتطلب: JDK 17، Android SDK 35، Gradle 8.9، NDK 27.2.12479018، CMake 3.22.1.

```
gradle -p android :app:assembleDebug --no-daemon
gradle -p android :app:assembleRelease --no-daemon
```

`assembleDebug` ينتج APK اختبار موقّع بمفتاح Debug. `assembleRelease` دون مفاتيح الإنتاج لا يعني حصولك على ملف موقّع. يحاول GitHub Actions بناء APK وتصحيحه ونشره كـ artifact.

## التوقيع الرسمي

سجّل الأسرار التالية في **Settings → Secrets and variables → Actions**، ولا ترسلها في المحادثات أو المستودع العام:

- `ANDROID_KEYSTORE_BASE64`: مفتاح JKS للإنتاج مشفّر Base64.
- `ANDROID_KEYSTORE_PASSWORD`: كلمة مرور المخزن.
- `ANDROID_KEY_ALIAS`: الاسم المستعار للمفتاح.
- `ANDROID_KEY_PASSWORD`: كلمة مرور المفتاح.

عند وجود هذه الأسرار، تُبنى حزمة Release موقّعة، وتُرفق في GitHub Actions. **لا تستبدل مفتاح التوقيع** بعد النشر الأول، وإلا فلن يمكن تثبيت نسخة جديدة فوق نسخة الإنتاج السابقة.

للتحديث فوق APK تجريبي سابق موقّع بـ Debug مختلف، قد يلزم إزالة ذلك التطبيق بعد حفظ بياناته؛ المحافظة على معرّف الحزمة وحدها لا تكفي للتحديث.

## التطوير المستقبلي

مشروع قارئ رسمي وليس محررًا إداريًا؛ إدارة المقالات والمسودات تستمر من الموقع. مزامنة المحتوى حاليًا عند فتح التطبيق أو الضغط على التحديث، وليست إشعارات لحظية. لا تستخدم واجهة القارئ كلمات سرّ/صلاحيات محلية للوصول إلى المسودات.
